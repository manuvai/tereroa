## Project Overview

Tereroa is a Spring Boot 3.3.0 MVP vehicle rental application (Turo clone) with read-only endpoints. Code is auto-generated from an OpenAPI specification.

## Build & Run Commands

```bash
# Build
./mvnw clean package

# Run tests
./mvnw test

# Run a single test class
./mvnw test -Dtest=VehicleServiceTest

# Run application (port 8080)
./mvnw spring-boot:run

# Docker build & run
docker build -t tereroa .
docker run -p 8080:8080 tereroa
```

## Architecture

**Layered architecture**: Controllers → Services → Repositories → H2 in-memory DB

- **OpenAPI code generation**: Controllers interfaces and DTOs are generated from `src/main/resources/static/openapi.yml` via the OpenAPI Generator Maven plugin (v7.6.0). Generated code lands in `fr.manuvai.tereroa.api` (interfaces) and `fr.manuvai.tereroa.api.models` (DTOs).
- **MapStruct mappers** (`fr.manuvai.tereroa.mappers`): Convert between JPA entities and generated DTOs at compile time.
- **Lombok**: Entities and generated DTOs use `@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor`.
- **Custom exceptions** use `@ResponseStatus` annotations (e.g., `NotFoundException` → 404).

### Domain Model

```
User ──owns──> Vehicle
User ──makes──> Reservation ──for──> Vehicle
```

### Key Packages (`fr.manuvai.tereroa`)

| Package | Purpose |
|---|---|
| `controllers` | REST controller implementations |
| `services` | Business logic |
| `repositories` | Spring Data JPA repositories |
| `models` | JPA entities (User, Vehicle, Reservation) |
| `mappers` | MapStruct entity↔DTO mappers |
| `exceptions` | Custom exceptions |
| `config` | SecurityConfig (permits all requests) |
| `api` | **Generated** controller interfaces |
| `api.models` | **Generated** DTOs |
